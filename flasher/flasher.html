USB firmware flasher for the Cheap Yellow Display — with device & SD detection.

Your browser can’t flash over USB

Flashing uses the Web Serial API, which only works in desktop Chrome or Edge over HTTPS (or localhost). Safari, Firefox, and phones/tablets (iOS/Android) can’t do it.

Open this page on a desktop in Chrome or Edge, plug in the board with a data USB cable, and try again.
