How it works

  1. Use desktop Chrome or Edge (they support Web Serial; Safari, Firefox and phones don't).
  2. Connect the CYD with a cable that carries data (not charge-only).
  3. Click Install / Update, pick the board's serial port (CP210x / CH340), and confirm.
  4. It flashes and reboots into the new build — nothing installs on your computer.

This does not delete your SD-card contents. If the port doesn't appear, install the USB-serial driver (CP210x or CH340) and reconnect.
